# Coral Island Guide CN

《Coral Island》指南的简体中文本地化版本。

本项目基于 [Koenigderluegner 的 Coral Island Guide](https://github.com/koenigderluegner/coral-island-guide) 开发。原项目及其贡献者保留其原有著作权；简体中文本地化、UI 改进及中文攻略内容由“南溟北榠”维护。

## 项目内容

- 简体中文界面与游戏资料本地化
- 面向中文玩家的 UI 与使用体验改进
- 中文攻略、地图和资料补充

## 本地开发

本项目使用 Node.js、pnpm、Angular 和 Nx。

```bash
pnpm install
pnpm build
```

## 上游项目

- 原项目：https://github.com/koenigderluegner/coral-island-guide
- 本仓库保留 `upstream` 远程地址，用于追踪原项目更新。
